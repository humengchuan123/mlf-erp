# Stage 3G 现金流量表设计

> 日期：2026-11-18
> 分支：`stage-3g-cash-flow`
> 状态：设计已确认

## 1. 目标

在现有总账、收付款和报表基础上增加现金流量表：

```text
现金/银行凭证
      ↓
按对方科目归类经营、投资、筹资项目
      ↓
直接法现金流量表主表
      ↓
净利润调节表（间接法附表）
```

## 2. 范围

### 本期

- 直接法现金流量表主表，按日期区间查询。
- 经营、投资、筹资三类现金流入、流出和净额。
- 期初现金、期末现金、现金净增加额。
- 标准现金流项目，按对方科目自动归类。
- 无法归类的现金分录进入“其他经营活动现金流”，并返回未分类凭证明细。
- 标准简化间接法附表：
  - 净利润
  - 非付现费用
  - 经营性应收、存货、应付、应交税费、应付职工薪酬变动
  - 间接法经营现金流净额
  - 直接法经营现金流净额
  - 差额
- SDK、OpenAPI、前端报表页签和自动化测试。

### 后置

- 现金流项目主数据和科目映射维护页面。
- 凭证行手工指定现金流项目。
- 现金流量预测、资金计划、直接法/间接法双列同比。
- 现金等价物范围配置。
- 合并现金流量表。

## 3. 标准现金流项目

### 3.1 经营活动

流入：

- `sales_receipts`：销售商品、提供劳务收到的现金
- `tax_refunds`：收到的税费返还
- `other_operating_inflows`：收到其他与经营活动有关的现金

流出：

- `purchase_payments`：购买商品、接受劳务支付的现金
- `employee_payments`：支付给职工以及为职工支付的现金
- `tax_payments`：支付的各项税费
- `other_operating_outflows`：支付其他与经营活动有关的现金

### 3.2 投资活动

流入：

- `disposal_asset_receipts`：处置固定资产、无形资产和其他长期资产收回的现金净额
- `other_investing_inflows`：收到其他与投资活动有关的现金

流出：

- `asset_purchases`：购建固定资产、无形资产和其他长期资产支付的现金
- `investment_payments`：投资支付的现金
- `other_investing_outflows`：支付其他与投资活动有关的现金

### 3.3 筹资活动

流入：

- `capital_injections`：吸收投资收到的现金
- `borrowings`：取得借款收到的现金
- `other_financing_inflows`：收到其他与筹资活动有关的现金

流出：

- `debt_repayments`：偿还债务支付的现金
- `dividend_interest_payments`：分配股利、利润或偿付利息支付的现金
- `other_financing_outflows`：支付其他与筹资活动有关的现金

### 3.4 现金及现金等价物

- 期初现金及现金等价物余额。
- 现金及现金等价物净增加额 = 经营净额 + 投资净额 + 筹资净额。
- 期末现金及现金等价物余额 = 截止日现金/银行科目余额。
- 当前现金等价物仅包含 `cash`、`bank` 科目映射，默认 `1001`、`1002`。

## 4. 科目自动映射

| 对方科目 | 现金流入 | 现金流出 |
|---|---|---|
| `1122` 应收账款 | 销售商品、提供劳务收到的现金 | 支付其他与经营活动有关的现金 |
| `2202` 应付账款 | 收到其他与经营活动有关的现金 | 购买商品、接受劳务支付的现金 |
| `1405` 库存商品 | 收到其他与经营活动有关的现金 | 购买商品、接受劳务支付的现金 |
| `2211` 应付职工薪酬 | 收到其他与经营活动有关的现金 | 支付给职工以及为职工支付的现金 |
| `2221` 应交税费 | 收到的税费返还 | 支付的各项税费 |
| `6001`、`6051` 收入 | 销售商品、提供劳务收到的现金 | 支付其他与经营活动有关的现金 |
| `6401`、`6601`、`6602`、`6603`、`6801` 成本费用 | 收到其他与经营活动有关的现金 | 支付其他与经营活动有关的现金 |
| `16xx`、`17xx` 固定资产/无形资产 | 处置固定资产、无形资产和其他长期资产收回的现金净额 | 购建固定资产、无形资产和其他长期资产支付的现金 |
| `1101` 交易性金融资产 | 收到其他与投资活动有关的现金 | 支付其他与投资活动有关的现金 |
| `1501`、`1511` 长期股权投资 | 收到其他与投资活动有关的现金 | 投资支付的现金 |
| `2001`、`2501` 借款 | 取得借款收到的现金 | 偿还债务支付的现金 |
| `4001` 实收资本 | 吸收投资收到的现金 | 支付其他与筹资活动有关的现金 |
| `4104` 利润分配 | 收到其他与筹资活动有关的现金 | 分配股利、利润或偿付利息支付的现金 |
| 其他科目 | 收到其他与经营活动有关的现金 | 支付其他与经营活动有关的现金 |

- 科目编码按前 4 位数字根匹配，支持 `112201`、`1122.01`、`222101`、`1002.01` 等子科目。
- 现金/银行映射也按根归一化；期初/期末余额查询必须使用相同的根语义。
- 未识别科目仍进入其他经营活动现金流，并标记为未分类。
- 无对方科目的现金分录进入其他经营活动现金流，并标记为未分类。
- 纯现金/银行互转不进入现金流项目。
- 未映射的常见科目（如 `6402`、`6403`、`6711`、`6301`、`1221`、`2241`）会进入其他经营并产生未分类提示，后续可按需补充映射。

## 5. 直接法计算

### 5.1 数据来源

- `gl_vouchers`：状态 `posted`、`reversed`，日期在查询区间内。
- `gl_voucher_lines`：现金/银行行和非现金对方行。
- `gl_accounts`：科目编码、名称、类型。
- `gl_account_mappings`：`cash`、`bank` 映射；可选 `non_cash_expense` 映射。

### 5.2 算法

1. 按凭证聚合所有分录。
2. 现金流入 = 现金/银行科目借方合计。
3. 现金流出 = 现金/银行科目贷方合计。
4. 现金流入按非现金贷方分录金额比例分摊。
5. 现金流出按非现金借方分录金额比例分摊。
6. 每条分摊金额四舍五入到 4 位，最后一条吸收尾差。
7. 按对方科目和流入/流出方向匹配标准项目。
8. 没有非现金对方分录：
   - 若现金流入和现金流出相等，视为内部现金/银行互转，忽略。
   - 否则进入其他经营活动现金流，并记录未分类明细。
9. 汇总各项目金额，计算三类活动净额和现金净增加额。
10. 期初和期末现金余额按现金/银行科目在区间起止日的总账余额计算。

### 5.3 未分类明细

每条未分类记录包含：

- 凭证 ID、凭证号、凭证日期。
- 流入/流出方向。
- 金额。
- 原因：无对方科目或未识别科目编码。

## 6. 间接法附表

### 6.1 调节公式

```text
净利润
+ 非付现费用
- 经营性应收项目增加
- 存货增加
+ 经营性应付项目增加
+ 应交税费增加
+ 应付职工薪酬增加
= 间接法经营活动现金流量净额
```

### 6.2 数据口径

- 净利润：复用利润表区间口径，排除期间结转和年度结转凭证。
- 非付现费用：从 `gl_account_mappings` 的 `non_cash_expense` 映射读取；没有映射时为 0。
- 经营性应收：`1122`。
- 存货：`1405`。
- 经营性应付：`2202`。
- 应交税费：`2221`。
- 应付职工薪酬：`2211`。
- 增加额 = 截止日余额 - 起始日前一日余额。
- 资产类余额 = 借方 - 贷方；负债类余额 = 贷方 - 借方。

### 6.3 勾稽

- 返回直接法经营净额和间接法经营净额。
- 返回差额 = 间接法净额 - 直接法净额。
- 差额不为零时前端显示提示，便于发现未分类、手工凭证或映射缺口。

## 11. 已知限制

- 科目映射按标准科目编码和前缀，未识别科目归入其他经营。
- 多对方科目按金额比例分摊，复杂手工凭证可能与人工判断存在差异。
- 当前现金等价物仅含现金和银行科目，未配置短期投资等现金等价物。
- 非付现费用依赖 `non_cash_expense` 映射，标准科目表没有折旧/摊销科目时显示 0。
- 间接法为简化调节表，差额用于提示分类缺口，不自动生成调整分录。
- 不提供凭证行手工现金流项目覆盖。
